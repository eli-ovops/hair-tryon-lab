# 真实发型试戴 MVP（throwaway）

这是一个分两阶段回答问题的本地交互原型：

1. 用户能否顺利完成三视图输入、发质约束、候选方向比较，并愿意把结果带给发型师。
2. 用户能否按正面 → 左转 → 回正 → 右转完成基于真实面部关键点的校准，并在有限转头范围内看到 2D/2.5D 发型轮廓持续跟随。

它不是生产产品，也没有接入真实换发 AI。页面保留用户原图，只叠加明确标注的发型轮廓、长度和颜色模拟层。模拟不代表剪后效果。

## 一条命令运行

```bash
cd /Users/USER/Documents/app/真实发型试戴MVP && python3 -m http.server 4173 --bind 127.0.0.1
```

打开：<http://127.0.0.1:4173/>

实时扫描入口：<http://127.0.0.1:4173/scan.html>

轻量变体：

- 引导式：<http://127.0.0.1:4173/?variant=guided>
- 紧凑式：<http://127.0.0.1:4173/?variant=compact>

## 测试流程

1. 上传正面、左侧、右侧三张图片，可替换、删除或全部清除。
2. 填写当前长度、发丝粗细、密度、自然纹理、灰发、限制、打理时间和高意图场景。
3. 从四个候选方向中选择 2–3 个。
4. 生成保留原图的三视图模拟比较，核对发量、正侧面一致性、现实可实现性和打理成本。
5. 点击“打印 / 另存为 PDF”，在浏览器打印面板中选择“另存为 PDF”。

## 实时扫描流程（第二阶段）

1. 打开 `/scan.html`，阅读隐私和 2D/2.5D 边界，主动点击开启摄像头。
2. 正脸居中并稳定保持，然后按提示缓慢左转、回正、右转；每关必须由真实关键点姿态保持约 0.9 秒通过。
3. 校准完成后切换“短层次”与“Bob”，观察轮廓的位置、缩放、roll、yaw 跟随。
4. 约超过左右 45° 会提示回到跟踪范围；页面承诺范围只有约 ±40°，不是 360°。
5. 点击“停止摄像头并清除状态”，确认摄像头 track 被释放。

自动化审计入口只用于测试，不代表用户摄像头验收：

- `scan.html?test=deny`：显式模拟 `NotAllowedError`。
- `scan.html?test=landmarks`：本地 canvas fake media + 可审计 landmark 序列，验证状态机和渲染逻辑。

实际用户摄像头跟踪质量必须由用户本人在 `/scan.html` 完成验收。

## 隐私与边界

- 照片通过浏览器 `URL.createObjectURL` 保留在当前标签页内存，不上传、不写入服务器、不建数据库。
- 刷新/关闭页面或点击“清除全部”会失去当前照片和输入。
- 本原型没有账号、分析、订阅、付费、外部 API 或模型 key。
- 实时扫描使用本地 vendored `@mediapipe/tasks-vision@1.0.1`、WASM 和 Google 官方 Face Landmarker 模型；运行时不依赖 CDN，也没有图像上传代码。
- 只使用你有权使用的本人照片；首轮测试建议 18 岁以上，勿上传未成年人面部照片。
- 结果不保证真实剪发、染发或造型效果，不能替代专业发型师判断。

## 文件

- `index.html`：流程与打印参考卡结构
- `styles.css`：响应式、模拟轮廓与打印样式
- `app.js`：页面内存状态、上传、候选比较、重置与变体逻辑
- `scan.html` / `scan.css` / `scan.js`：实时扫描入口、摄像头、关键点跟踪和发型轮廓
- `scan-machine.js`：纯校准状态机
- `vendor/`：固定版本的 MediaPipe JS/WASM、模型和依赖边界记录
- `evidence/`：非用户隐私测试素材与 smoke 证据
