# THROWAWAY：hair-only mask / pixel-lock Spike

**问题**：针对同一合成样本的正面、左侧图，是否能够把“仅允许头发及必要遮挡缓冲区变化”变成可审计的像素门禁，并据此拒绝整图重绘的 Bob 结果？

这是一次性证据工具，不属于 App、不会进入 iOS bundle，也不消费真实用户照片。选择 prototype 的逻辑分支：这里验证的是像素锁定数据/门禁，而不是界面外观；状态以 `output/results.json` 全量输出。

## 运行

```sh
python3 evidence/throwaway-hair-only-mask-spike-2026-08-07/run_spike.py
```

运行会从前一轮独立 Bob Spike 读取同尺寸的正/左合成输入和整图重绘候选，生成手工校准的头发、脸、耳、颈蒙版，热图和统计。它不下载模型、不调用网络、不修改 App 文件。

## 重要边界

- 本项目没有可核验真人正/左/右许可素材；输入只能说明合成演示样本上的视觉一致性，不能证明真人身份保持。
- 当前 ImageGen 调用接口只接受 `prompt` 和参考图路径；没有可传入、可回读的显式 binary mask / protected-region 参数。因此该工具不能满足生产级像素锁定；本 Spike 不用“提示词说不要改脸”冒充蒙版编辑。
- 本轮只有正面与左侧。没有右视源图，因此绝不生成或评价推断右视。
- 蒙版为针对这两个固定夹具的人工近似校准，不冒充模型分割精度。它是拒绝不合格候选的保护性门禁，而不是可泛化的分割器。
