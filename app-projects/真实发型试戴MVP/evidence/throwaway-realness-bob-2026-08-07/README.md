状态：进行中。此目录是一次性技术 Spike，**不属于 App 资源、不会被打包或集成**。

## 要回答的问题

在不改动人脸、肤质、头型、年龄、背景和视角的约束下，多参考图编辑能否把同一合成样本改成短 Bob，并在正面、左侧、模型推断的右侧保持足够的视觉连续性，明显优于 2D 轮廓贴图，作为与发型师沟通的参考。

## 失败门槛

任一项明显失败即不进入 Pixie / Coily：脸部或肤质漂移、发际线不自然、耳朵或颈部错误遮挡、贴图感、虚增发量、发质失真、左右视图不连贯；以及由于缺少右侧原图而无法做严格右侧保真对照。

生成结果将只作为视觉一致性证据，标注“生成式 Spike / 合成主体”，不宣称真实 AI 试戴、实时 AR、100 款生成或可用于真实用户。
