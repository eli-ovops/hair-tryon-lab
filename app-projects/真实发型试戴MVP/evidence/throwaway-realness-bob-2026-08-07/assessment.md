# Bob 结果评估（生成式 Spike / 合成主体）

## 方法与产物

- 生成方式：一次 ImageGen 多参考图编辑；主输入为项目内 `scan-placeholder-front.png` 与 `scan-placeholder-side.png`。
- 提示词约束：三联图（正、左、模型推断右），保持脸、五官、肤质、头型、年龄、背景、服装、光线与各视角；只将长发改为自然密度的下颌 Bob；禁止美颜、瘦脸、增发量、改背景或加配饰。
- 原始生成总图：`output/bob-three-view-generated.png`（1823 × 863）。
- 同尺寸单图：`input-front-same-size.png` / `bob-front.png`、`input-left-same-size.png` / `bob-left.png`，均为 607 × 863。`bob-right-inferred.png` 同尺寸，但**无右侧原图可对照**。
- 每一个输出都只是生成式重渲染，不能从像素近似推导出身份保持。

## 逐项人工目视（不是自动评分）

| 项目 | 观察 | 结论 |
|---|---|---|
| 脸漂移 | 主体仍可辨认为同一合成样本，但眼睑、目光、鼻唇细节与肩颈姿态被重新渲染；不是可验证的原脸锁定。 | 失败（真实性门槛） |
| 发际线 | 中/偏中分与头皮过渡自然，未见明显硬边。 | 暂通过（视觉） |
| 耳朵 / 颈部遮挡 | 两侧耳朵和颈线保持可见，Bob 末端未见明显穿插。 | 暂通过（视觉） |
| 边缘贴图感 | 发丝边缘和颌角附近过渡自然，明显优于原 App 的 Canvas 轮廓贴图。 | 暂通过（静态视觉） |
| 发量 | 由长发变 Bob 后轮廓合理，未见明显凭空增厚；但没有真实头皮/密度量测。 | 有条件通过 |
| 发质 | 深色直发的方向与反光基本连续，细丝层次仍偏生成式平滑。 | 有条件通过 |
| 左右视图一致性 | 三联图轮廓大致一致，但右侧是模型推断，不存在同一主体右视原图；不能验证跨视图真实性。 | 失败（证据缺口） |

## 决策

**NO-GO：停止 Pixie / Coily。** 这组结果说明生成式编辑在合成样本上可得到比 2D 贴图更自然的静态 Bob 外观，但没有通过“真人身份、三视图严格一致、可作为理发前可靠参考”的门槛：输入本身为项目演示/合成资产、无可核验肖像/拍摄授权；缺少右视真值；输出仍有脸部与姿态的重渲染漂移。

下一步只有在取得明确许可、可由用户控制的同一真人正/左/右照片（以及对所用服务、留存、训练用途的单独授权）后，才可重复同一质量门禁。该 Spike 不得集成到 App，亦不得表述为真实 AI 试戴、实时 AR 或 100 款生成。
