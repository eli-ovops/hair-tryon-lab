# 设计预览 A+C Override

## 视觉来源与使用方式

- A：`设计方案/imagegen/A-编辑感松绿.png`。继承温白/骨白、深松绿底部行动区、真实人物照片为主与轻编辑感。
- C：`设计方案/imagegen/C-清透原生蓝.png`。继承原生手机的单任务布局、紧凑 filmstrip、低文字密度与清晰的底部操作。
- 新预览仅裁取上述用户提供的 Image Gen 图中的人物/发型区域，文件位于 `设计预览-A+C/assets/`；不是竞品素材。整张参考 PNG 不作为页面背景。

## A+C Tokens

| 项目 | 值 |
|---|---|
| 底色 | `#F7F3EC` 温白 |
| 主行动 | `#153E34` 深松绿 |
| 强调 | `#B5684B` 极少量陶土色 |
| 文字 | `#17372F` 深绿黑 |
| 字体 | 系统 sans + Georgia 展示字 |
| 控件 | 14px 主按钮圆角、12px 图片圆角、弱 1px 分隔线 |

## 禁止项

不使用紫粉渐变、AI sparkle、glassmorphism、bento 卡片、满屏 pills、重复免责声明、竞品截图或外部字体/脚本。每屏一项任务、一枚主 CTA；全局只保留“设计预览”小标记。
