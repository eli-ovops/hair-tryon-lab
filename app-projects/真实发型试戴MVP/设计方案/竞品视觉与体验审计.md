## 共同评价

- **值得借鉴**：相机中的清晰引导、选择器的减少负担、并排对比、结果交付到线下专家、显性隐私提示。
- **应避免**：紫粉生成气泡、人像美颜与发型决策混用、大量滤镜卡、对“真实”的超范围承诺、在结果后突然强订阅。
- **无障碍缺口**：商店截图不足以验证键盘、可读性、动效降级或付费打断。我们不将他们的展示当成无障碍通过的证据。

## 跨案例视觉 / UX 维度对照

| 维度 | 官方页/店面可见模式 | 我们的处理 |
|---|---|---|
| 首屏承诺 | 大多以“即刻变身”、“热门款”或“更上镜”为标题。 | “先说清楚，再剪下去”：主动降低假定的准确性。 |
| 相机占比 / 扫描 | 美颜类以滤镜、生成结果和网格为主；眼镜 / 彩妆 AR 的引导更强。 | 摄像头首先占屏，但用 4 段进度定义它是校准，不是神奇滤镜。 |
| 发型选择器 | 大库、carousel、热门款或“上传任意参考图”。 | 3–4 个有原因的“方向”，卡上显示长度、发质、打理的后果。 |
| 比较 / 交付 | 优势是 before/after、保存、社交分享、购买或订阅。 | 并排三视图 + 可实现性注释 + 发型师问题。不做社交发布为主 CTA。 |
| 隐私 / 信任 | 多数商店在底部链接隐私。Hairli 是少数将不存照片写入特性的案例。 | 在授权前画面明说本地处理、停止、清除、不录制。 |
| 色彩 / 字体 / 圆角 / 动效 | 发型/美颜类通常以高饱和效果图、圆角卡、“前后对比”惊喜来刺激点击。细粒度 token 不应由商店截图反推。 | 温白+炭黑+深松绿，纸张注释、Newsreader + Inter、20px 发型卡、150–220ms 有意义的微动效。 |
| 失败恢复 | 商店截图几乎不展示拒绝权限、丢跟或低光。 | 将拒绝、丢跟、角度超限、低光、多人、停止写入同一套状态规格。 |
