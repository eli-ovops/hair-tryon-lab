# 竞品产品流与 UI 借鉴

日期：2026-08-07  
范围：YouCam Makeup、FaceApp、AirBrush、Facetune、HairApp、HairStyle AI、HairTune  
证据：本轮美国 App Store 官方截图、官方功能说明与官方帮助页面。截图只能证明展示结构与公开流程，不能证明每个 App 的真实触摸、生成质量或可访问性实现。

## 总体结论

成熟竞品已经证明四个模式无需重新发明：

1. 用户照片必须成为屏幕主角，工具退到底部。
2. 发型与颜色用横向缩略选择器，选中后立即有可见反馈。
3. 前后对比是结果页的常驻能力，不藏在二级菜单。
4. “上传照片 → 选择 → 生成 → 保存”必须短而直接。

我们不能照搬它们的核心缺陷：把发型混进泛美颜工具箱、默认只收正面照、修改脸部、虚增发量、只给漂亮结果、用 credits 阻断首次验证、把紫蓝渐变当作 AI 高级感。

我们的超越点不是增加更多编辑按钮，而是让结果更值得用于真实剪发决定：三视角、原脸保护、现实发量、失败结果拦截、可实现性说明和发型师参考卡。

## 竞品逐项拆解

### 1. YouCam Makeup

![YouCam Hairstyle Try On](../evidence/竞品UI-2026-08-07/raw/youcam-5.jpg)

公开流程：导入清晰正面照 → 浏览 150+ 发型或上传参考发型 → 生成结果。

健康度：入口和选择器成熟；作为剪发决策工具偏弱。

值得借鉴：

- 人像几乎占满屏幕，底部只露出必要的发型卡。
- 选中卡有明显描边，用户无需猜当前款式。
- 前后分割线让变化一眼可见。
- 发型、发色和参考图输入属于用户已经理解的心智模型。

主要风险：

- 发型与瘦脸、美肤、身体编辑、AI 视频等并列，用户目标容易被稀释。
- 官方流程仍以正面照为核心，没有展示侧面一致性。
- “自然、超真实”是营销主张，截图不能证明现实发量或身份保持。

### 2. FaceApp

![FaceApp Hairstyle](../evidence/竞品UI-2026-08-07/raw/faceapp-2.jpg)

公开流程：选择照片 → 进入滤镜文件夹 → 选择 Hairstyles/Hair Colors → 可叠加多个滤镜 → 比较并保存。

健康度：编辑心智与即时反馈很强；原脸真实性与发型决策目标冲突。

值得借鉴：

- 工具被组织成文件夹，避免所有功能铺满屏幕。
- 底部卡片数量受控，当前项状态清楚。
- 随时比较、收藏和保存预设，适合反复探索。
- 顶部短标题与完整照片形成清晰层级。

主要风险：

- 同一产品明确支持脸型、皮肤、微笑、年龄和发量修改，无法建立“不会改脸”的默认信任。
- 发型截图展示的是单角度美化结果。
- 可叠加滤镜虽然灵活，也让最终变化来源难以追溯。

### 3. AirBrush

![AirBrush Hair](../evidence/竞品UI-2026-08-07/raw/airbrush-7.jpg)

公开流程：导入照片 → 底部编辑工具 → Hair Dye/Hairstyles/Hairline/Bangs → 调整 → 保存。

健康度：编辑器导航清晰；更接近发色与局部修图，不是完整发型决策流程。

值得借鉴：

- 底部四项用图标和文字并列，功能边界容易理解。
- 全屏照片、局部 before 圆形预览和 AFTER 标签建立即时反馈。
- 品牌色强且一致，工具层级稳定。

主要风险：

- 发型只是编辑器中的一个工具，缺少从采集到决策的连续路径。
- 强橙色和高饱和营销感不适合我们的现实、冷静定位。
- 截图重点是颜色变化，没有多角度或发量依据。

### 4. Facetune

![Facetune Hair Editor](../evidence/竞品UI-2026-08-07/raw/facetune-1.jpg)

公开流程：添加设备照片 → 底部工具进入 Hair/Haircuts/Hair Color → 选择或输入目标 → 生成/应用 → 保存。

健康度：视觉最简洁、时装感最强；核心价值仍是自我编辑与美化。

值得借鉴：

- 画面极简，输入框/单一动作浮在照片底部，不与人像竞争。
- 工具图标统一、背景安静、留白克制。
- 提供提示词与预设两种选择方式，兼顾快速与表达自由。
- 进入和退出编辑器路径符合成熟照片 App 心智。

主要风险：

- 提示词自由度会制造“什么都能实现”的错觉。
- 依然使用单张正面照片，且与皮肤、脸型、妆容工具同属一个编辑器。
- 网页编辑器在上传前要求同意人脸模型与人脸数据处理，说明远程生成的信任成本真实存在。

### 5. HairApp

![HairApp Try On](../evidence/竞品UI-2026-08-07/raw/hairapp-1.jpg)

![HairApp Face Analysis](../evidence/竞品UI-2026-08-07/raw/hairapp-8.jpg)

公开结构：发型试戴、发色、脸型分析、色彩分析、AI 发型师，以及与头发无关的妆容、指甲、服装等工具。

健康度：头发入口清楚；功能膨胀明显，分析结果存在伪精确风险。

值得借鉴：

- 试戴首屏直接采用 before/after 分割，发型缩略图紧邻结果。
- Face Shape Analysis 提供从分析到推荐的叙事连续性。
- 深色分析页让照片和结果更突出。
- 对话式 AI 发型师可以帮助用户把模糊想法变成可选方向。

主要风险：

- 3.9/5、“黄金比例”等分数制造不必要的审美评判和伪科学感。
- 发型、妆容、指甲、服装混在一起，破坏专业聚焦。
- 仍然是单张结果，未展示现实发量和侧面。

### 6. HairStyle AI

![HairStyle AI Photo Analysis](../evidence/竞品UI-2026-08-07/raw/hairstyleai-1.jpg)

![HairStyle AI Style Selection](../evidence/竞品UI-2026-08-07/raw/hairstyleai-7.jpg)

![HairStyle AI Customization](../evidence/竞品UI-2026-08-07/raw/hairstyleai-8.jpg)

![HairStyle AI Barber Result](../evidence/竞品UI-2026-08-07/raw/hairstyleai-5.jpg)

公开流程：选择性别/款式 → 添加或拍摄正面照 → 照片质量检查 → 选择发型与颜色 → 可调长度、纹理、轮廓、刘海 → 消耗 credits 生成 → 保存或展示给理发师。

健康度：单任务流程最接近我们的产品；视觉通用、技术承诺仍停留在单正面图。

值得借鉴：

- 在消耗 credit 前做照片质量检查，失败成本前置。
- 一个屏幕完成照片、发型、颜色和生成，路径非常短。
- 自定义放入底部 sheet，不挤压主流程。
- 结果页直接写款式名、颜色和日期，并突出给理发师展示。
- 每日免费尝试降低首次验证门槛。

主要风险：

- 只有正面照，官方质量检查还会阻止侧脸；无法回答侧面效果。
- 长度、纹理、轮廓、刘海四条滑杆暗示连续精确控制，但生成模型未必能可靠兑现。
- 生成前显示 `3 Credits`，用户可能在看到价值前离开。
- 紫蓝渐变、黑底和发光图标是常见 AI 模板，品牌辨识度弱。
- 商店尚无足够评分，不能把界面完整等同于市场验证。

### 7. HairTune

![HairTune Home](../evidence/竞品UI-2026-08-07/raw/hairtune-4.jpg)

公开结构：首页只有 Hairstyle Change、Hair Color Change 两个大入口，并在底部展示 Pro 升级。

健康度：极易理解；内容和差异化较薄。

值得借鉴：

- 两个大任务卡比十几个小工具更容易开始。
- 入口图就是结果示例，用户不用读说明。

主要风险：

- Pro 卡占据首屏显著空间，可能早于价值展示。
- 视觉与常见模板接近，缺少专业判断和发型师交接。

## 复用矩阵

| 模式 | 来源 | 我们如何复用 | 我们如何超越 |
|---|---|---|---|
| 照片主导、工具退到底部 | YouCam、FaceApp、Facetune | 采集和结果页始终让本人照片占最大面积 | 同屏提供正/左/右视角与现实状态 |
| 发型缩略横条 | YouCam、FaceApp、HairApp | 只展示当前筛选后的少量候选，清楚选中态 | 每张卡标明可生成/实验中/仅目录，并显示现实适配 |
| 前后分割对比 | YouCam、AirBrush、HairApp | 结果页常驻，可拖动也可一键切换 | 对比只改变头发区，脸部变化触发质量拒绝 |
| 底部工具栏 | AirBrush、Facetune | 视角、发型、颜色三个上下文工具 | 不塞入皮肤、脸型、身体编辑 |
| 生成前照片检查 | HairStyle AI | 在计算和付费前检查方向、清晰度、遮挡 | 正/左/右分别检查，只重拍失败角度 |
| 自定义底部 sheet | HairStyle AI | 高级条件渐进展开 | 用离散现实选项替代伪精确连续滑杆 |
| 收藏/预设 | FaceApp | 保存 2–3 个候选用于比较 | 保存现实约束和理由，不只保存效果 |
| 给理发师展示 | HairStyle AI | 结果页直接进入参考卡 | 三视图、发质、限制、备注形成真正交接材料 |
| 免费首次体验 | HairStyle AI | 首次用户至少完成一款完整比较 | 不在结果前用订阅墙或 credits 截断验证 |

## 我们的产品结构

### 首次使用：单线流程，不显示底部主导航

1. **开始**：一句话价值 + `开始扫描`，次要入口 `使用三张照片`。
2. **采集**：正面通过 → 左转 → 回正 → 右转；失败只重拍当前角度。
3. **现实档案**：长度、卷度、密度三个必填；其他条件渐进展开。
4. **选发型**：照片在上、发型卡在下；默认显示最相关的 6–12 款，不先铺 100 款。
5. **生成**：显示三视角共同生成状态；允许取消，失败保留输入。
6. **结果**：正面默认，可切左/右；常驻对比；显示现实要求。
7. **下一步**：`再试一款` 或 `保存参考`，只保留一个主按钮。

### 首次结果后：三项底部导航

1. **试戴**：扫描状态、当前照片和继续试款。
2. **对比**：最多 3 款，同一视角横向比较。
3. **参考卡**：已选择方案、三视图、现实要求和用户备注。

不设置“首页、发现、AI、商城、我的”等与核心决策无关的一级入口。设置、隐私和删除会话放在右上角次级菜单。

### 跳转原则

- 前进使用系统一致的左入或淡入；返回保留扫描、筛选和滚动位置。
- 首次采集是全屏任务，不用可随意拖走的底部 sheet。
- 发型高级选项使用可关闭的底部 sheet，并提供明确完成按钮。
- 横滑只用于发型缩略条和视角选择；页面主体始终纵向滚动，避免系统返回手势冲突。
- 结果页返回发型目录时不重新扫描；从参考卡返回时保留当前候选。
- 所有看似可点击的控件必须有 44×44pt 触摸区、按下反馈和禁用状态。

## 视觉决定

### 保留

- 温白背景、炭黑正文、深松绿主动作、低饱和陶土辅助色。
- 照片与真实发丝纹理承担视觉冲击，不靠渐变和发光制造高级感。
- 简洁人文标题 + 系统友好的正文层级。
- 轻量纸张/发型师记录感，但不用大量说明文字。

### 局部使用深色

- 相机取景与结果全屏查看可以使用炭黑背景，提升照片聚焦。
- 深色只服务于观看，不作为全 App 的“AI 主题”。

### 明确避免

- 紫蓝渐变、霓虹光圈、漂浮 AI 球和发光机器人图标。
- 大面积玻璃拟态、随机阴影与多个不同圆角。
- 用美化模特图替代真实产品状态。
- 把描述文字、隐私说明和技术声明长期压在相机画面上。
- 只靠粉色描边表达选中；同时使用勾选、标题或位置状态。

## 高优先级超越清单

1. 三视角是同一次生成，不是三个独立结果。
2. 原脸保护区发生明显变化时，系统拒绝结果。
3. 用户低密度/细软/灰发/卷发条件实际进入结果和说明。
4. 不可实现的款式明确说明需要留长、烫发、染色、增发或高维护。
5. 在首次完整结果前不展示订阅墙或 credits 消耗焦虑。
6. 结果不是分享海报优先，而是比较和发型师交接优先。
7. 100 款目录不冒充 100 款已验证生成；真实支持范围清楚可见。

## 证据限制

- 本轮无法直接进入每款付费 iOS App 的完整交互流程；官方截图与说明可证明公开结构，不能证明真实触摸、延迟、错误态或生成质量。
- App Store 美国页面在应用内浏览器发生地区跳转，因此截图通过 Apple iTunes Lookup API 返回的官方截图地址获取，并逐张本地检查。
- FaceApp、YouCam 等商店评分证明产品规模，不证明发型功能本身的满意度。
- HairStyle AI 商店尚无足够评分，只能作为近期单任务产品模式参考。
