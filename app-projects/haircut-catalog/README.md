交付物：
- `women-50.json` — 女性 50 款完整目录

## A. 目录设计原则与分类数量分布

### A.1 目录设计原则

1. **剪裁几何优先，命名其次**。每一款先定义唯一的「剪裁指纹」——轮廓（silhouette）+ 层次策略（layering）+ 刘海结构（bangs）+ 长度落点（length）+ 纹理（texture）——再据此命名。指纹五元组不允许任意两款完全相同，因此不会出现"换发色 / 改名字 / 微调长度"凑数的情况。

2. **现实可执行是硬门槛**。所有条目对应的都是理发店常用术语与手法：贴剪、堆积（graduation）、等长（one-length）、点剪、削剪（razor）、渐变（fade）、下梳（comb-over）等。不收纯舞台造型、假发、高幻想造型。唯一需要专门技能的编发款（cornrow fade）已在 `stylistInstruction` 与 `realisticFor` 中明确标注"需要编发师"，不伪装成普通剪发。

3. **发质是适配条件，不是凑数手段**。`texture` / `densityFit` 表示"这款剪裁适合什么真实发质"，与 `realisticFor` / `notIdealFor` 联动；灰发款（silver pixie、silver long layers、silver short crop、silver wavy medium）明确表述为"自然灰发过渡"，是发质条件而非染色造型。所有图片提示词一律默认自然发色。

4. **性别只是浏览筛选**。女性与男性目录各自独立 50 款；同名跨性别款（buzz、french crop、wolf cut、shag、mullet 等）在剪裁细节上做了真实可执行的差异处理（例如女性圆寸留长 1–3 mm、保留自然发际线不做推光），使两个目录内部都不出现重复条目。差异清单见 D.1。

5. **三视图必须同一身份**。每一款固定一个「身份锚」：性别、大致年龄段、族裔、自然发色、发量。三个 image prompt 复用同一身份锚，保证正面 / 左侧 / 右侧描述的是同一个人、同一个剪裁。

6. **多样性按身份锚分配**。100 款的身份锚覆盖多种族背景与自然发色，但不把族裔与发型做刻板绑定，也不靠改变脸型 / 年龄 / 妆容 / 肤质制造差异。

## D. 重复检查报告

### D.1 跨性别同名款（最容易混淆，已按现实差异区分）

| 组合 | 明确差异 |
|---|---|
| 女性圆寸 vs 男性圆寸 | 女性版 6–8mm 等长、保留自然发际线不推光、顶部略长 1–2mm 柔化轮廓；男性版 3–5mm 均匀、可加轻渐变。 |
| 女性法式短发 vs 男性法式短发 | 女性版顶部 3–5cm、刘海更长更柔、两侧 1–2cm；男性版顶部 2–4cm、刘海更碎更短、两侧更贴。 |
| 女性狼剪 vs 男性狼剪 | 女性版耳侧蓬起外翻、后尾 5–10cm、更柔和；男性版更短更硬朗、后尾更短、冠部层次更强。 |
| 女性乱发 vs 男性中长乱发 | 女性版层次落差大、碎刘海明显、蓬度强；男性 shaggy-medium 层次松散、更随性自然、不做强碎刘海。 |
| 女性现代鲻鱼头 vs 男性鲻鱼头 | 女性版卷发更蓬、前顶更短碎、后尾更长更柔；男性版经典前短后长、后尾至肩、层次过渡自然。 |

### D.2 女性目录内最易混淆的组合

| 组合 | 明确差异 |
|---|---|
| 齐剪鲍勃 vs 法式鲍勃 | 两者皆齐剪：blunt bob 至下巴、无固定刘海、一字齐边；french bob 更短（耳下至下巴）、配厚齐眉刘海、发尾内扣更 compact。 |
| 前长后短鲍勃 vs 倒置鲍勃 | A-line 是后短前长的一条连续斜线、无堆积；inverted 在后颈 2–4cm 做厚重堆积层次、前长后厚。 |
| 前长后短鲍勃 vs 不对称鲍勃 | A-line 差异在前后；asymmetrical 差异在左右（一侧耳上、一侧至下颌）。 |
| 卷发鲍勃 vs 短卷圆剪 | curly bob 卷发至下颌、饱满圆廓保留 bob 形；short curly crop 紧密卷贴头均匀圆廓、无 bob 角、更短。 |
| 乱发 vs 狼剪 vs 蝴蝶剪 | shag 层次均匀分布全头、长度中短；wolf 顶部短蓬 + 后留长尾（鲻鱼倾向）；butterfly 仅面部短层外翻 + 下层长发量、层次只在前。 |
| 乱发 vs 卷发乱发 | 同廓形、不同发质适配：shag 面向直/波浪（湿剪），curly shag 面向自然卷（干剪、点剪去重）。 |
| U形层次 vs V形层次 | 后部发尾圆 U 弧 vs 尖 V 角，其余参数一致。 |
| U形层次 vs 圆形层次 | U-cut 无内层、轮廓由外缘线决定；round layers 有内层短于外层的层次、形成内扣圆弧、整体更蓬。 |
| 中长V形 vs 长V形 | 同一剪法思路，长度落点不同（medium 至肩 vs long 至胸下）。 |
| 长齐剪 vs 等长直发 | long blunt 至胸、适配 medium/thick、发尾厚重垂坠；one-length 强调纯几何单一切口、适配 fine/medium、更贴垂。 |
| 沙滩波浪长鲍勃 vs 波浪鲍勃 | 长度不同：lob 至锁骨 vs bob 至耳下肩内；波浪密度与造型手法相同但廓形落点不同。 |
| 长帘刘海 vs 面部框层次 | 前者有完整帘式刘海 + 全头长层；后者仅面部两侧短层、其余几乎零层。 |
| 长螺旋卷 vs 长紧密卷 | 卷度类型不同：spiral curls（弹性螺旋、中等蓬度）vs coils（紧密卷、收缩明显、蓬度大）。 |
| 银灰精灵 vs 经典精灵 | 剪裁更短更碎（接近 micro-textured 级别），且明确为自然灰发发质条件款；经典精灵为通用发质。 |

### D.3 男性目录内最易混淆的组合

| 组合 | 明确差异 |
|---|---|
| 贴皮寸 / 圆寸 / 板寸 / 高紧寸 | 长度递进与顶部形态：1–2mm 全头 / 3–5mm 全头 / 顶部 10–20mm + 侧渐短 / 顶部 15mm + 侧 1–3mm 高位过渡线。 |
| 渐变圆寸 vs 皮肤渐变圆寸 | tapered 底部 1–2mm 不推光、顶部 12–15mm、柔和；skin fade 底部推至头皮、顶部约 10mm、对比锐利。 |
| 锥形渐变 / 低渐变 / 高渐变 / 皮肤渐变 / 下坠渐变 / 放射渐变 | 渐变起点与形状：taper 收至发际线不推光；low 从耳上开始、保留侧发量；high 从太阳穴上方开始；skin 推至头皮；drop 后颈沿头骨下坠弧线；burst 以耳为圆心放射。 |
| 凯撒剪 vs 法式短发 vs 纹理短发 | 都有短刘海：caesar 顶部短平 + 齐厚刘海向前压平；french crop 顶部 2–4cm 碎 + 纹理刘海眉上；textured crop 无固定刘海、自然斜分、更轻盈。 |
| 常春藤 vs 经典侧分 | ivy league 顶部 2–4cm 短、分线柔和无硬线；classic side part 顶部 6–9cm 更长、侧分明确正式。 |
| 蓬巴杜 vs 奎夫 | pompadour 顶部光滑高弧向后上方、光泽定型；quiff 顶部向前上方抓、碎感哑光、前额竖起。 |
| 蓬巴杜 vs 后梳油头 | pompadour 前额高弧向后；slicked back 全头向后顺梳贴服、无前弧。 |
| 后梳油头 vs 上长下削渐变 | slicked 顶部 5–8cm 全后梳、两侧渐短不推；undercut fade 顶部 6–9cm、两侧推短渐变、上下对比更强。 |
| 高紧寸 vs 高渐变 | high-and-tight 是 buzz 级（顶 10–20mm 直立、侧 1–3mm）；high fade 是 crop 级（顶 2–5cm 碎发 + 渐变从太阳穴上方）。 |
| 卷顶渐变 / 卷发放射渐变 / 圆卷渐变 | 均为卷 + 渐变：curly top fade 顶部卷 5–8cm 圆顶 + 普通渐变；curly burst fade 顶部卷 4–7cm + 耳周放射渐变；afro taper 为 coily 紧密卷 + 侧后沿卷度渐收、边缘利落。 |
| 自然圆蓬 / 卷发分界圆蓬 / 长紧密卷 | afro full 均匀圆蓬无分线；curly parted fro 圆蓬带明确分线更整理；long coily 更长（收缩后及肩）。 |
| 男士丸子头 vs 男士低马尾 | 高丸子（冠部）vs 低马尾（颈背），束发位置与形态不同。 |
| 波浪流动 vs 中分长波浪 | 长度不同（颈上/肩上 vs 及肩或更长），后者为中分帘式。 |
| 中长乱发 vs 长乱发 | 长度不同（颈上 vs 胸下），长版冠部层次更强、发尾更碎。 |
| 鲻鱼头 vs 狼剪 | mullet 经典前短后长、后尾至肩、过渡自然；wolf 顶部与刘海更短更蓬、层次落差更大、更前卫。 |
| 现代锅盖 vs 齐额厚刘海 | bowl 全头圆廓 + 齐刘海 + 两侧垂至耳垂（碗形）；heavy fringe 顶部 8–12cm 自然垂落、刘海厚但两侧渐短、不呈碗形。 |
| 梳盖 vs 经典侧分 | comb over 顶部 6–10cm 横向梳盖针对稀疏区、fine 发质；classic side part 均匀发量、侧分更正式。 |
| 平顶 vs 板寸 | flat top 顶部竖直修剪成水平平台、顶侧直角；crew cut 顶部自然直立无平台。 |

## E. ImageGen 批量生成建议

### E.1 如何保持同一人物三视图一致

1. **身份锚复用**：每一款已内置唯一「身份锚」字符串（年龄 + 族裔 + 自然发色 + 发量 + 发型摘要）。正面 / 左侧 / 右侧三个 prompt 必须逐字复用同一身份锚，只允许替换视角短语（`Front view` → `Left side profile view` → `Right side profile view`）与视角补充描述（哪侧耳、哪侧鬓角、刘海起止方向）。
2. **正面图定身份，侧面图以正面为参考**：推荐先生成正面图作为该款的"身份基准图"，再以 img2img / 参考图（reference / controlnet）方式生成左、右视图，强制同一张脸、同一发色、同一发量。禁止三个视图独立文生图。
3. **环境参数逐字锁定**：背景色、光线短语、镜头距离（`camera at eye level, chest-up`）、约束短语（5 条）在三个 prompt 中逐字不变。
4. **同款同批**：同一款的 3 张图必须在同一批次、同一参考图体系内完成，禁止跨天 / 跨批次补拍某一张。
5. **生成后抽查**：人工目检三视图的脸部相似度、发色一致性、后脑轮廓一致性（这部分的视觉验收建议在 Codex 侧做）。

### E.2 推荐的批次大小

- **最小单元**：每款 3 视图一批（front / left / right）。
- **建议批次**：每批 4–6 款，即 12–18 张图。理由：便于在检错后整款返工，又不至于因单款失败拖累全批；每批完成后先跑一次失败判定再进入下一批。
- 灰发款（4 款）单独成批，便于统一校验"自然灰发"未被染色化。

### E.3 失败图判定标准（满足任一条即废）

1. 出现 AI 塑料质感、磨皮、美颜、皮肤被平滑 → 废。
2. 发量明显多于该款声明发质（虚增、假发感、蓬度过载）→ 废。
3. 三视图之间人物脸、发色、发量、光线不一致 → 废。
4. 发际线、鬓角、耳周、后脑轮廓、层次或发尾被遮挡 / 不可见 → 废。
5. 与知名真人过于相似 → 废。
6. 发型在物理上无法由理发师剪出（悬空发、无支撑体积、反重力）→ 废。
7. 通过改变脸型、年龄、妆容、肤质制造发型差异 → 废。

### E.4 最容易出问题的发型

| 风险 | 发型 | 建议抑制措施 |
|---|---|---|
| 发量虚增（高发险） | 乱发 / 狼剪 / 蝴蝶剪 / 自然圆蓬 / 卷发鲍勃 / 卷发精灵 / 蓬巴杜 / 奎夫 / 平顶 | prompt 中显式加入 `moderate natural volume`、`no added density`、卷发类加 `natural shrinkage, moderate curl volume` |
| 侧面不一致 | 不对称鲍勃（左右差）、削边精灵（隐藏下削）、硬分线侧分（分线位置）、下坠渐变 / 放射渐变（渐变形状）、V形/U形（后部尖/圆弧） | 侧视 prompt 增加"描述该侧具体特征"的语句（已在各款左侧/右侧 prompt 中落实），生成时强制以正面为参考 |
| 不现实 | 好莱坞波浪（光泽过度像假发）、玉米辫渐变（编发细节错误）、平顶（平台不真实）、男士丸子头（丸子过大） | 增加 `realistic salon finish`、编发款标注 braid 方向一致 |
| 身份漂移 | 所有卷发 / 长发款（因生成器常"美化"长发） | 严格复用身份锚 + 参考图流程 |

## 使用边界说明

- 本目录为内容规划与提示词工程交付物，不包含 App 代码，不声称已接入任何 App。
- 静态参考图仅用于帮助用户理解剪裁方向，不等同于真实试戴效果；试戴效果需以 App 内的实时渲染 / 真人剪发为准。
- 发型命名不复制任何竞品名称或素材；英文名采用行业通用术语（Bob、Pixie、Fade 等）以避免受保护创意文案。
